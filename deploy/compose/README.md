# Development Compose stack

Milestone 0 provisions only shared infrastructure: PostgreSQL, ClickHouse, and NATS JetStream. CERBERO application services are added to Compose in the milestones that implement them; empty/fake service containers are intentionally avoided.

The development Raw Store is a host filesystem tree under `var/raw/`, because STORAGE v1 locks an object/file-based Raw Store but leaves the production object-store implementation open.

## Start

```bash
make dev-init
make dev-up
make dev-bootstrap
make dev-health
```

The `.env` generated by `make dev-init` contains only DEVELOPMENT ONLY credentials copied from `.env.example`. It is ignored by Git.

The numeric JetStream byte limits are local capacity safeguards, not production retention decisions.
