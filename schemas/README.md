# Schemas

This directory is the governed root for CERBERO wire and validation schemas.

- `protobuf/`: internal contracts and event-bus payload contracts (Milestone 1).
- `jsonschema/`: JSON Schema definitions used where JSON is the supported wire/config format.
- `ocsf/`: pinned OCSF metadata and CERBERO mapping compatibility data (Milestone 4).

No placeholder `.proto` contract is created in Milestone 0: the first real contracts are delivered and compatibility-tested in Milestone 1.
