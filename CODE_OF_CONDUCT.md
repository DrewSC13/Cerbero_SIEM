# Code of Conduct

CERBERO contributors are expected to maintain a professional, technically rigorous, and harassment-free collaboration environment.

## Expected behavior

- Discuss ideas and implementations on their technical merits.
- Give review feedback that is specific, actionable, and respectful.
- Accept correction when evidence shows an implementation or assumption is wrong.
- Protect private vulnerability information, credentials, personal data, and other sensitive material.
- Credit external work and respect third-party licenses.

## Unacceptable behavior

Harassment, threats, discriminatory conduct, deliberate disclosure of private information, impersonation, sabotage, or knowingly introducing malicious code or compromised dependencies is not acceptable.

## Enforcement

Concerns should be reported privately to the project maintainers. Once the remote repository is configured, the private reporting/contact mechanism documented in `SECURITY.md` becomes the canonical channel. Maintainers may remove content or participation that violates this policy, with actions proportionate to severity and project safety.

This project-specific policy may later be superseded by a formally adopted community code through an ADR/documentation change.
